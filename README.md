# 🍽️ MERN Restaurant Reservation

A full-stack restaurant reservation web application built with the MERN stack. It provides a responsive interface for exploring a restaurant, viewing menu and team information, and making table reservations online.

## ✨ Features

- 🍽️ Restaurant landing page
- 📖 Menu section
- 🪑 Online table reservation
- 👨‍🍳 Restaurant and team information
- 📱 Responsive design
- ⚡ Fast and modern frontend
- 🔗 REST API for reservations
- 🗄️ MongoDB database integration
- 🚨 Backend error handling
- ✅ Reservation success page
- ❌ 404 Not Found page

🚀 Getting Started
Clone the Repository
git clone https://github.com/yashkesarwani2004/MERN-Restaurant-Reservation.git
cd MERN-Restaurant-Reservation
💻 Frontend Setup
cd frontend
npm install
npm run dev
⚙️ Backend Setup

Open another terminal:

cd backend
npm install
npm start
Environment Variables

If environment variables are required, create a .env file inside the backend folder.

Example:

PORT=5000
MONGO_URI=your_mongodb_connection_string

Never upload passwords, API keys, database credentials, or other sensitive information to GitHub.
